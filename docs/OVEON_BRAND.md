# 오브온 · OVEON

## 브랜드 정의

나의 취향으로 일상을 켜다. 기존 단어의 사전적 어원이 아닌, 이름에 부여한 브랜드의 의미다.
‘오브’는 취향이 담긴 물건인 오브제를 떠올리게 하는 소리이고, ‘온’은 ON, 온전히 나다운 일상, 온기를 뜻한다.
옷은 나를 표현하고, 뷰티는 나를 돌보며, 홈은 내가 머무는 공간을 채운다.

로고의 O는 취향을 담는 공간이며 작은 점은 취향이 켜지는 순간을 나타낸다.
SVG 워드마크는 외부 폰트에 의존하지 않는 벡터 선으로 제작했다.

## 매장

- `/`: 의류. 뉴트럴 톤.
- `/beauty`: 뷰티. 로즈 톤.
- `/home`: 홈. 올리브와 크림 톤.

상품의 `department`가 상품 조회, 카테고리와 캐시를 분리한다. 기존 상품은 `fashion`이다.

## 새 상품 정보

코스알엑스 26개와 펌리빙 26개는 공식 공개 상품 메타데이터를 바탕으로 한국어 상품명과 소개를 구성했다.

- https://www.cosrx.com/products.json
- https://fermliving.com/collections/furniture/products.json

원본 상품 주소는 각 상품의 `additional_info.상품정보출처`에 보존한다.
이미지는 공식 원본 CDN 주소를 사용하며, 상품 정보 접근이 사진의 재사용 허가를 의미하지는 않는다.
오브온 판매가격은 별도 등록가격이며 공식 판매처의 가격이나 실시간 환산가격을 표방하지 않는다.
용량·치수는 임의로 만들지 않았고 가격이 다른 용량/묶음은 고정 판매 구성을 표시한다.
가격이 같은 실제 색상 선택만 옵션으로 제공한다. 새 상품의 구매 후기와 판매 이력은 생성하지 않는다.

`npx tsx scripts/seed-lifestyle.ts`는 0027 마이그레이션을 적용하고 고정 ID로 상품을 추가한다.
동일 ID는 다시 덮어쓰지 않아 운영자가 수정한 정보를 보존한다. 기존 상품·계정·주문은 삭제하지 않는다.
