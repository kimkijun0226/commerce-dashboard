# 오브온 배너 탐색·태그 검색·운영 관리자

목표: 배너 전체 클릭으로 관련 상품을 찾고, 관리자가 상품·로고·배너·주문 배송을 실제 데이터로 운영한다.

1. `lib/catalog/campaigns.ts`, StorefrontCampaign/HomePage/StorefrontPage: 매장별 배너 대상, URL 필터, 새로고침·뒤로가기 유지. 카테고리·태그 검색 회귀 테스트.
2. `lib/catalog/filters.ts`, `keywords.ts`: #태그와 분리된 단어 AND 검색, 태그 입력 검증. 기존 검색 회귀 검사.
3. migration 0028: 매장 설정과 관리자 전용 이미지 저장소, 주문 배송 필드. 기존 고객·주문·권한 유지. 공개 설정 SELECT와 관리자 쓰기 RLS 검사.
4. `app/admin` 및 `components/admin`: 기존 레이아웃 재사용, 실제 집계 대시보드, 페이지 단위 상품 목록/등록/수정, 태그 칩·이미지 업로드, 로고/배너 설정, 주문 배송 상세. 모든 mutation에서 관리자 확인과 서버 검증.
5. 검증된 기존 한국 의류 메타데이터와 공식 라이프스타일 상품에서 중복 없이 상품 추가. 실제 이미지 응답 확인, 리뷰·주문·매출 생성 금지. 소스와 정책 기록.
6. 타입·린트·검색/폼/배송 검증 테스트·프로덕션 빌드·공개 UI·비인가 접근 검사 후 배포. 관리자 로그인 세션이 없으면 실제 저장 테스트 한계를 명시.
