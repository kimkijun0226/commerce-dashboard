# 현재 쇼핑몰의 한국어 의류 카탈로그

현재 연결된 쇼핑몰에 국내 브랜드 의류 180개를 구성합니다. 티셔츠·셔츠·팬츠·니트·자켓·코트 각 30개이며, 다른 사용자의 상품 카테고리를 의류로 제한하는 코드는 추가하지 않습니다. 관리자 UI·로고·쇼핑몰별 소유권·대시보드는 후속 작업입니다.

## 상품·사진 출처

- Habin Kim, [K-Fashion Visual Distinctiveness 공개 메타데이터](https://huggingface.co/datasets/HabinKim/kfashion-visual-distinctiveness).
- 원본 버전과 필터링 내역: `scripts/data/fashion-source.json`.
- 메타데이터 라이선스: [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/).
- 원본 한국어 상품명과 원화 가격을 사용하고 배송·적립 광고 문구를 정리했습니다. 상품 설명·세탁 안내는 별도로 작성했으며, 원본에 없는 소재 비율·실측 치수·재고는 임의로 만들지 않았습니다.
- 사진은 원본 네이버 쇼핑 이미지 URL을 참조합니다. 메타데이터 라이선스가 사진의 상업적 이용권을 부여하지는 않습니다. 실제 공개 판매 시 판매자가 사용할 수 있는 상품 사진과 공급·가격·재고를 확인해야 합니다.

`fashion-products.json`에는 서로 다른 대표 사진을 가진 상품만 담고, 같은 모델 코드의 중복 판매 글과 실패한 이미지 주소를 제외했습니다. 이전 DummyJSON 상품·사진은 현재 카탈로그에서 제거합니다.

## 한국어 리뷰

`scripts/data/korean-review-copy.ts`는 의류별 핏·기장·코디를 다루는 한국어 문구를 구성합니다. 상품당 12~26건으로, 평점·작성자 표시·날짜를 분산합니다. `is_generated = true`로 실제 구매 후기와 구분하고 화면에도 ‘구성된 리뷰’를 표시합니다. 작성자는 마스킹한 가상 표시 이름이며 로그인 계정·주문·결제는 생성하지 않습니다.

실제 고객 리뷰는 기존처럼 로그인 사용자와 결제 완료 주문이 필요합니다. 외부/구성 리뷰는 일반 고객의 INSERT/UPDATE 권한으로 등록하거나 변조할 수 없습니다.

## 실행

```sh
node --import tsx scripts/seed-fashion.ts --check
yarn db:seed-fashion
```

두 번째 명령은 고정 ID로 없는 상품·리뷰만 추가합니다. 재실행 시 중복 생성하거나 관리자가 수정한 상품을 덮어쓰지 않습니다. `.env.local`의 `SUPABASE_ACCESS_TOKEN`, `NEXT_PUBLIC_SUPABASE_URL`을 사용하며 필요한 리뷰 스키마도 적용합니다.

카탈로그 내용을 다시 적용하려면:

```sh
yarn db:seed-fashion --refresh-catalog
```

이 스크립트 소유 상품·리뷰만 갱신합니다. 이전 15개 DummyJSON 상품의 외부 리뷰를 지우고, 구매 이력이 없는 이전 상품은 삭제합니다. 구매 이력이 있으면 숨김으로 보존합니다. 고객 작성 리뷰·다른 상품·주문·계정은 유지합니다.

**쇼핑몰 데이터 전체 초기화가 명시적으로 필요한 경우에만:**

```sh
yarn db:seed-fashion --reset-commerce
```

전체 초기화 대상은 상품·리뷰·주문·주문 항목·결제·장바구니·찜·배송지·연동 설정입니다. 로그인 계정과 `public.users`, 마이그레이션 이력은 보존합니다. 갱신/초기화 전에 OS 임시 폴더의 `commerce-dashboard-backups/`에 접근 권한 0600인 JSON 백업을 남기고 경로를 출력합니다. 임시 폴더는 영구 보관 장소가 아닙니다. 데이터 변경은 트랜잭션으로 실행하며 중간 오류 시 롤백합니다.

## 이미지 최적화

상품 카드·상세·장바구니·주문·찜에서 허용된 이미지 호스트에 Next.js 크기 조정·캐시를 적용합니다. 상세 갤러리는 공간을 고정하고 지연 로딩합니다. 아직 허용하지 않은 사용자 이미지 호스트는 직접 로딩하여 기존 동작을 보존합니다.

```sh
node --import tsx --test commons/utils/imageOptimization.test.ts
```

## 홈 카테고리·검색

카테고리 배열은 넓은 분류, 쇼핑 카테고리, 선택 태그 순서입니다. 홈 카테고리는 두 번째 값을 사용하고, 값이 없으면 첫 번째 분류를 사용합니다. 카테고리별 개수와 필터는 같은 DB 기준으로 집계합니다.

홈 검색은 350ms 디바운스를 적용하며 카테고리·검색어 조합마다 별도 쿼리 캐시와 페이지를 사용합니다. 검색 중에도 다음 페이지를 조회할 수 있고, 이전 요청은 취소합니다. 띄어쓰기 변형을 지원하고 쉼표·따옴표·와일드카드 문자를 안전하게 처리합니다.

```sh
node --import tsx --test lib/catalog/filters.test.ts
```
